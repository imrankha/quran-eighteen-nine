# quran-eighteen-nine

A web app listing all **89 ayaat** of the Quran that contain
**"يَـٰٓأَيُّهَا ٱلَّذِينَ ءَامَنُوا۟" (Ya ayyuhal lazeena amanu — "O you who have believed")**.

Pick an ayah from the dropdown to see:

- the Arabic text (Uthmani script)
- **word-by-word meaning** with transliteration: Urdu, Hinglish, English, Hindi, Bengali, Indonesian, Turkish or Persian
- **translation** in Urdu, Hinglish (Roman Urdu), English, Hindi, Bengali, Tamil, Telugu, Malayalam, Marathi, Gujarati, Kannada, Persian, Indonesian, Turkish, French, Spanish, German or Russian

**Urdu and Hinglish are on by default.** You can turn on any number of languages, and your choice is saved in the browser.
Other features: search by surah, ayah number (e.g. `2:153`) or meaning; previous/next buttons (or the ← → keys); and shareable links such as `index.html#2:183`.

## Run locally

It's a static site with no build step. Serve the folder over HTTP, because the browser has to `fetch` the JSON files:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

It works on any static host (GitHub Pages, Netlify, etc.).

## Data

All files in `data/` are generated by `scripts/build_data.py`:

```bash
cd scripts && python3 build_data.py
```

- The ayah list is every verse that contains `يا أيها الذين آمنوا` in the `quran-simple-clean` text from [AlQuran.cloud](https://alquran.cloud).
- Arabic text, translations and word-by-word meanings come from the [Quran.com API v4](https://api-docs.quran.com).
  - Urdu: Fatah Muhammad Jalandhari
  - Hinglish: Abul Ala Maududi (Roman Urdu)
  - The translator for each other language is shown in the app.
- **Hinglish word-by-word meanings are auto-transliterated** from Quran.com's Hindi word-by-word data by `scripts/hinglish.py`. Where Quran.com has no Hindi meaning for a word, it supplies an English one, and that English text is shown as-is.
